One short funny line answering a prompt — the excuse a smart fridge gives after ordering forty gallons of milk: it blamed autocorrect, because it thought 'low fat' meant 'low on everything.' `main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt`, with a gate that checks it is one non-blank line of 1–200 UTF-8 characters and verifies the written file round-trips exactly.
